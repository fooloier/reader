# Reader 阅读器

Reader 是原生 GPUI 桌面书库，支持 PDF 和 EPUB。书籍保存在应用管理的副本中，导入、重命名和删除都不改动原始文件。

## 启动阅读器

准备 Rust 工具链、GPUI 所需的系统图形开发库，以及可用的桌面图形会话。中文显示需要系统安装中文字体，例如 Noto CJK。已验证环境为 Linux、Wayland、Hyprland；其他平台尚未实机验证。

在项目根目录运行：

```text
cargo run --locked --bin reader
```

首次启动显示空书架。点击文件图标选择 PDF 或 EPUB，或点击文件夹图标递归导入文件夹。每个书籍文件独立处理，失败项显示在窗口底部。文件夹内的非书籍和嵌套符号链接计为跳过；直接选中的符号链接会解析到目标。直接选择不支持的文件会显示错误。相同内容再次导入会跳过，并保留已有书名和阅读位置。

## 管理和阅读书籍

- 点击书卡或列表中的书名打开书籍。**书架**标签固定保留，同一本书只有一个标签。
- 在书架点击重命名图标修改显示书名。托管文件名同时更新，原始元数据不变。
- 点击删除图标后确认删除。确认框说明将移除托管副本和进度，保留原始文件。
- 点击书架工具栏中的布局图标切换卡片和列表，点击太阳或月亮图标切换主题。
- 阅读时点击左侧面板图标显示书内目录与书签，点击齿轮显示设置。按 Escape 关闭面板并返回触发按钮。
- PDF 支持连续滚动、上一页、下一页、缩放、适合宽度和适合整页。深色主题不会反转 PDF 页面颜色。
- EPUB 支持目录跳转、正文内部链接、上一章、下一章，以及字体、字号、行距、段距和正文宽度设置。
- 拖选正文后按 Ctrl+C 复制；macOS 使用 Cmd+C。PDF 选择限于单页，EPUB 选择限于一个正文块。

阅读位置、打开的标签、主题和格式设置自动保存。EPUB 排版和 PDF 缩放分别应用于所有同格式书籍，不按单本保存。字体选择来自当前系统，默认使用系统字体；不可用的已保存字体会回退到系统字体。关闭标签后重新打开会恢复进度，正常退出后再次启动也会恢复。

关闭窗口或按退出快捷键后，应用显示保存状态，等待已排队任务和最终快照落盘后退出。保存失败会留在窗口中显示错误，可修复数据目录后重试。强制结束进程或操作系统杀死应用可能丢失尚未落盘的位置和设置。

## 键盘操作

Linux 和 Windows 使用 Ctrl，macOS 使用 Cmd。

| 组合键 | 操作 |
| --- | --- |
| Ctrl+O | 导入文件 |
| Ctrl+Shift+O | 导入文件夹 |
| Ctrl+, | 设置 |
| Ctrl+W | 关闭当前书籍标签 |
| Ctrl+Q | 退出 |
| Escape | 关闭当前弹层 |

## 支持范围

EPUB 使用受控原生重排，保留标题、段落、粗体、斜体、列表、表格、图片和内部链接。出版社的任意 CSS、嵌入字体、音视频、脚本与复杂排版不保真。固定版式会拒绝导入。竖排来源按受控横向重排显示，不保留原书的书写方向。支持常见 XHTML XML 声明、DOCTYPE、HTML 命名实体、SVG 图片封面和空章节，不加载外部 DTD，拒绝自定义 DTD 实体。部分未支持的 HTML 语义会退化为普通文本。

本版本没有 TXT、OCR、全文搜索、分类、筛选、个人书签编辑或批注功能。目录面板显示书内导航；PDF 大纲和 EPUB 目录按层级缩进，无法解析的目标会禁用。加密 PDF 没有密码输入流程。PDF 创建日期不作为出版年份。当前没有解析 PDF XMP 出版日期，PDF 出版年份显示未知；EPUB 使用书内日期元数据。

导入文件上限为 512 MiB；EPUB 正文合计上限为 32 MiB，图片资源合计上限为 64 MiB；每章最多 100000 个 XML 节点、128 层嵌套。文件夹每个导入根最多遍历 100000 项、64 层；托管文件名的书名部分最多 160 个 UTF-8 字节。书架和 EPUB 当前章节尚未做虚拟列表，超大书库或单章内容很长时可能变慢。EPUB 图片解码缓存每会话最多保留 32 项，此限制不是严格的显存字节上限。

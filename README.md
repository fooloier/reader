# Reader 阅读器

Reader 是基于 GPUI 的本地桌面电子书阅读器，支持 PDF 和 EPUB。将书籍导入统一书架，在多个标签间切换，并在下次打开时继续阅读。

## 功能

- 导入单个文件或递归导入文件夹，读取封面、书名、作者和出版信息，跳过重复内容。
- 卡片与表格两种书架布局；表格支持拖动调整列宽。
- 重命名与删除书籍。导入保存应用管理的副本，操作不改动原始文件。
- PDF 连续滚动、翻页、缩放、适合宽度和整页显示。
- EPUB 目录与正文链接跳转，调整字体、字号、行距、段距和正文宽度。
- 正文选择与复制、明暗主题、阅读位置和打开标签恢复。

## 启动

需要 Rust 工具链、GPUI 所需的系统图形开发库和可用的桌面图形会话。中文阅读建议安装 Noto CJK 等中文字体。已在 Linux / Wayland / Hyprland 环境验证；macOS 和 Windows 尚未实机验证。

在项目根目录运行：

```sh
cargo run --locked --bin reader
```

首次启动为空书架。点击文件图标导入 PDF 或 EPUB，或点击文件夹图标批量导入。点击书卡封面或列表书名开始阅读。新导入或最近从书架打开的书籍排在最前，卡片和列表顺序一致，重启后保留。重复导入、阅读进度保存和启动时自动恢复标签不改变顺序。

## 下载自动构建

推送 tag 后，GitHub Actions 会构建 Linux amd64 版本。在仓库 Releases 页面的对应 tag 下下载 `reader-linux-amd64.tar.gz`：

```sh
tar -xzf reader-linux-amd64.tar.gz
./reader-linux-amd64/reader
```

该版本在 Ubuntu 24.04 上构建，使用系统动态库；运行环境仍需兼容的系统库、图形会话和 Vulkan 驱动。

## 构建

构建开发版本：

```sh
cargo build --locked --bin reader
./target/debug/reader
```

构建优化版本：

```sh
cargo build --locked --release --bin reader
./target/release/reader
```

以上路径适用于未设置自定义 Cargo 输出目录的构建。首次构建需要下载依赖；缺少系统开发库时按编译器报告补齐对应依赖。仓库没有独立安装器，上述命令直接运行构建产物。

## 使用

在卡片右下角的省略号菜单或表格行的右键菜单中重命名、删除书籍。删除会移除托管副本和阅读进度，确认前请检查目标书籍。

阅读时通过左侧面板按钮查看书内目录与书签，通过齿轮打开设置。设置按格式应用于同类书籍；阅读位置按书籍记忆。正常关闭窗口时等待保存完成；保存失败会显示错误并允许重试。

Linux 和 Windows 使用 Ctrl，macOS 使用 Cmd：

| 按键 | 操作 |
| --- | --- |
| Ctrl+O | 导入文件 |
| Ctrl+Shift+O | 导入文件夹 |
| Ctrl+, | 设置 |
| Ctrl+W | 关闭当前书籍标签 |
| Ctrl+Q | 保存并退出 |
| 左 / 右方向键、PageUp / PageDown | 上一页或章、下一页或章 |
| Escape | 关闭弹层 |
| Ctrl+C | 复制选中文字 |

翻页快捷键在阅读界面使用，输入框和弹层会拦截相应操作。

## 支持边界

EPUB 使用原生重排，不保证还原出版社的任意 CSS、嵌入字体或复杂版式；固定版式不支持。PDF 深色主题保持页面原色。文字选择范围为 PDF 单页或 EPUB 单个正文块。

目前不提供 TXT、OCR、全文搜索、分类、筛选、个人书签编辑或批注；加密 PDF 没有密码输入流程。出版信息缺失时显示未知，不用文件创建时间替代出版日期。

# Reader 的状态与存储

Reader 将领域状态、文件存储和桌面会话分开，以便在没有 GPUI 的情况下验证导入和恢复。`reader-core` 只依赖 serde，`reader-runtime` 持有文件与格式服务，桌面层为每个打开的 BookId 创建一个 ReadingSession。

## 状态归属

`BookId` 标识书籍。内容摘要用于去重，显示书名和原始元数据分别保存。PDF 位置记录页号与页内比例；EPUB 位置记录正文资源 href 与稳定块锚点。两种格式的阅读设置采用不同类型。排版和缩放是全局的格式设置，阅读位置按书籍保存。目录中的书签来自出版物，不创建个人书签。

`Service` 的单个工作线程拥有 `Library` 和 SQLite 连接。界面提交任务并等待结果，渲染函数不读取文件或数据库。每本书的异步加载绑定对应实体；会话关闭后丢弃加载结果，位置写入还要求数据库中的 BookId 存在。SQLite 自增 ID 不复用已删除书籍的身份。任务边界捕获 panic 并返回诊断，后续任务仍可执行；这不构成任意任务代码的事务回滚。

EPUB 通过 rbook 读取元数据、正文、目录和图片。XHTML 先移除不含内部子集的 DOCTYPE，并将标准 HTML 命名实体转为 XML 数字实体，再由有节点数限制的 XML 解析器校验。自定义实体、无效 XML 和超过嵌套上限的章节会拒绝。解析过程不获取外部 DTD。空章节保留，SVG 图片包装转换为图片块。混合容器中的连续内联内容组成同一块，保留粗体等格式，再交给可选择的 Markdown TextView。

资源、目录和内部链接采用同一套 URL 规范化规则。先分离路径和片段，再分别解码和编码；路径按段处理，字面百分号和井号不会变成二次解码或片段边界。XML 中的锚点保持原文，保存位置恢复时只编码一次。无法解析的目录目标禁用。字体或图片导致布局变化时，视口重新对齐目标块；用户滚动后停止自动对齐。延迟帧回调携带导航版本，旧布局回调不能覆盖新的跳转目标。位置精度是块级，不是任意字符或段内像素。

PDF 使用本地 vendored gpui-pdf 0.7.0。补丁提供宿主工具栏、加载事件和视口读写，等待布局完成后恢复位置。页面渲染与提取文字缓存限定在阅读窗口附近，关闭时释放页面纹理。EPUB 图片缓存最多保留 32 项，按最近使用顺序淘汰，换章和会话释放时清理。书架封面缓存最多保留 64 项。

## 文件归属与恢复

导入先复制到 staging，并对复制后的内容计算 SHA-256。内容已存在时直接跳过。解析成功后将文件放入 books，完成目录同步，再写入数据库。原始路径只作为输入使用。

重命名先创建并同步新副本，更新数据库，再删除旧副本。删除先移除数据库记录，再清理工作区和文件。启动恢复只删除 staging 中的临时文件。未被数据库引用的托管原件原地保留，数据库丢失或重置后也不会删除这些文件。文件缺失的书籍记录、元数据和位置保留，启动显示路径诊断，打开时报告错误；恢复原路径文件后可继续阅读。丢失的已知封面可从托管书籍重建。

SQLite 使用 WAL 和 FULL 同步。设置与工作区 JSON 使用临时文件、同步和原子替换。书库进程锁阻止两个进程同时写入同一书库。损坏或数值无效的设置和工作区 JSON 会先按原始字节备份为 `.corrupt-N`，使用默认值并显示启动诊断。重复启动不会重复备份相同损坏内容。

窗口关闭和退出快捷键进入统一的异步保存状态。界面停止接收新操作，会话先采集最新位置，再等待服务队列及位置、设置、工作区最终写入成功，最后调用 GPUI 退出。保存失败会显示错误并恢复交互，可以重试。这个过程在 GPUI 的 200 ms 退出回调期限之前完成，不依赖退出回调完成后台任务。

集成测试会在真实导入部分写入 staging 后杀掉隔离进程，再重启验证清理。其他孤立原件、缺失记录和数据库重置场景使用显式构造的状态。这些测试没有覆盖断电、磁盘损坏和全部文件系统故障，也不保证强制杀进程时尚在内存中的最新进度。

## 原生目录

Linux 只接受绝对路径的 XDG 环境变量；相对路径或缺失值使用下表默认目录。

| 内容 | 环境变量 | 默认路径 |
| --- | --- | --- |
| 托管书籍、SQLite、阅读进度、锁、staging | XDG_DATA_HOME | ~/.local/share/reader |
| settings.json | XDG_CONFIG_HOME | ~/.config/reader |
| 可重建封面 | XDG_CACHE_HOME | ~/.cache/reader |
| workspace.json | XDG_STATE_HOME | ~/.local/state/reader |

macOS 和 Windows 通过 `directories::BaseDirs` 获取系统原生数据、配置和缓存目录。工作区位于原生本地数据目录的 reader/state。启动恢复诊断和操作错误显示在窗口中，部分底层诊断写入标准错误，没有持续日志文件。

| 模块 | 职责 |
| --- | --- |
| crates/core | 书籍身份、位置、设置、标签状态 |
| crates/runtime/src/library.rs | 导入、去重、持久化、重命名、删除、恢复 |
| crates/runtime/src/formats.rs | PDF 与 EPUB 元数据和封面 |
| crates/runtime/src/epub.rs | EPUB 块模型、目录、内部资源 |
| src/app.rs | 应用状态、标签、异步任务与退出保存 |
| src/shelf.rs、toolbar.rs | 书架与工具栏 |
| src/overlays.rs、settings.rs | 对话框、目录和设置面板 |
| src/reading | 每本书的会话、EPUB 视口与图片缓存 |
| vendor/gpui-pdf/PATCHES.md | PDF 补丁范围与来源 |
